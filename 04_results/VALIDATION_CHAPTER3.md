# 第 3 章验证：闭环总结（2026-11-11）

思路：逐级加入一个新因素，每一级都有独立参照（闭合解或有限元），上一级通过后，下一级的差别只能来自新加入的因素。

| 级别 | 新加入的因素 | 参照 | 主要指标与差别 | 文件 |
|---|---|---|---|---|
| 0 | 围岩非关联 MC 塑性 + 开挖–安装–运营历史（轴对称） | 闭合解 | 接触压力 0.001%，洞壁位移 0.014%，屈服前沿半径 0.09%；首次反向屈服 4.41 MPa | `sa_axisymmetric/closed_form_comparison.json` |
| 1 | 开裂配筋衬砌 + 钢板（分层正交异性环），弹性围岩，无脱空 | 有限元 V5_B00_EL_medium | 接触压力 0.005%，位移、钢板应力、混凝土应力 ≤ 0.09% | `fem_v5/V5_B00_EL_medium_vs_SA.csv` |
| 2 | 局部脱空（界面分段、端点奇异性） | 有限元 V5_B10_EL_medium；分段收敛 + Richardson 外推 | 钢板峰值 0.2%（外推值 0.1%），脱空段位移 0.2%，周向分布 L2 ≤ 0.2%；8192 分段 GCI 0.11% | `fem_v5/comparison_B10_EL/`，`elastic_sa/panel_convergence/` |
| 3 | 二维围岩塑性场（64×512），无脱空 | 闭合解（有限元 V5_B00_EP_medium 同时验证） | 有限元与闭合解 ≤ 0.2%；开挖塑性区深度：SA 0.86 m，闭合解 0.92 m（一个单元内） | `fem_v5/comparison_B00_EP/` |
| 4 | 脱空 + 围岩塑性耦合 | 有限元 V5_B10_EP coarse / medium（两者相差 < 1%，网格收敛） | 见下 | `fem_v5/comparison_B10_EP/` |

第 4 级（β = 10°，1–10 MPa，medium 相对 SA）：

- 平均接触压力 ≤ 0.1%，接触段位移 ≤ 0.7%，衬砌混凝土最大主应力 −2.5% ~ +0.7%；
- 钢板峰值 −0.9% ~ −3.8%，全程 SA ≥ FE（SA 偏安全）；其中约 0.6% 来自 SA 2048 分段本身的偏高（第 2 级分段收敛）；
- 脱空段平均位移 −0.6% ~ +6.4%，差别随塑性发展增大；
- 塑性区最大深度 max(开挖, 运营)（阈值 1e-6，依据见 `fem_v5/comparison_B10_EP/plastic_depth_threshold_check.csv`）：≤ 8 MPa 时差 ≤ 0.2 m，9–10 MPa 时 FE 深 0.3–0.4 m（约 13%，此段 FE 本身对网格也敏感）。

第 4 级的剩余差别只在"脱空 + 塑性"同时存在时出现（第 2、3 级都 ≤ 0.2%），且有限元网格已收敛，因此来自两种模型对端点附近塑性的处理不同。
最可能的原因是塑性势：Abaqus Mohr–Coulomb 采用光滑塑性势（Menétrey–Willam 型），SA 采用经典非关联势，两者在轴对称应力状态下相同（第 3 级吻合），
在脱空端点附近 Lode 角变化时流动方向不同；其次是 SA 围岩网格（环向 0.7°）在端点处的分辨率。未用额外计算区分这两者。

验证的范围（论文中应说明）：

- 这是"方法正确性"的验证：两种模型采用相同的开裂刚度（α = 0.05）、钢筋线弹性、粘结界面假定；这些假定本身不在验证范围内；
- 弹塑性 + 脱空只验证了 β = 10°；参数分析中的其他脱空尺寸依赖第 2 级（弹性、任意 β 的界面处理）与第 3 级（塑性）的分别验证；
- 钢板首次屈服判据所用的钢板峰值应力，SA 在全部压力下不低于 FE，用于容许脱空尺寸评价偏安全。

补充检查（只用 SA，已完成）：β = 10°、1024 分段与 2048 分段的弹塑性计算对比（`sa_ep/B10_P1024/` 与 `sa_ep/B10_P2048/`，1–10 MPa）：

| 指标 | 1024 相对 2048（弹塑性，1–10 MPa） | 弹性同一对比（10 MPa，`elastic_sa/panel_convergence/`） |
|---|---|---|
| 钢板峰值 | +1.13% ~ +1.22% | +1.16% |
| 脱空段平均位移 | +0.41% ~ +0.56% | +0.56% |
| 接触段位移、平均接触压力 | < 0.01% | < 0.01% |
| 衬砌混凝土最大主应力 | +0.56% ~ +0.60% | — |
| 塑性外半径（塑性区深度） | 0 | — |
| 塑性区面积 | ≤ 0.4%（4 MPa 时塑性区很小，4%） | — |

结论：弹塑性情况下分段数的影响与弹性情况相同（钢板峰值每加密一倍降低约 1.2%，单调收敛到同一极限），围岩塑性区不受界面分段影响。
因此第 4 级中 2048 分段 SA 钢板峰值的分段误差可直接引用第 2 级的 Richardson 外推结果（约 0.6%，偏大即偏安全），无需额外的有限元计算。
